# Pertemuan 1: Bahasa Pemrograman Dart

Dokumentasi dan catatan praktikum Modul 1 (Bahasa Pemrograman Dart).

---

## 📌 Materi yang Dipelajari
1. **Hello World:** Menjalankan sintaks dasar Dart dan mencetak output ke konsol (`print`).
2. **Tipe Data:** Mengenal tipe data dasar seperti `int`, `double`, `String`, `bool`, dan deklarasi otomatis dengan `var`.
3. **Operasi Matematika & Logika:** Melakukan operasi aritmatika (`+`, `/`, dll) dan operator logika perbandingan (`>`).
4. **Struktur Kontrol:** Penggunaan percabangan `if-else` dan perulangan `for` serta `while`.
5. **Fungsi:** Pembuatan dan pemanggilan fungsi dengan parameter dan nilai kembalian (*return value*).
6. **Kelas dan Objek (OOP):** Konsep OOP, *class*, atribut, *constructor*, *method*, dan instansiasi objek `Mahasiswa`.
7. **Import Library:** Menggunakan pustaka internal Dart (`dart:math`) untuk menghasilkan bilangan acak (`Random`).
8. **Eksepsi (Exception Handling):** Menangani error pada runtime menggunakan blok `try-catch` dan `on Exception`.
9. **Async & Await:** Mengelola proses asinkronus menggunakan `Future`, `async`, dan `await Future.delayed`.
