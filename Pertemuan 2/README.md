# Pertemuan 2: Pengenalan dan Desain Framework Flutter

Dokumentasi dan catatan praktikum Modul 2 (Pengenalan dan Desain Framework Flutter).

---

## 📌 Materi yang Dipelajari
1. **Stateless vs Stateful Widget:** Perbedaan widget statis tanpa state (`StatelessWidget`) dan widget interaktif dengan state dinamis (`StatefulWidget`).
2. **Hello World:** Membuat tampilan pertama menggunakan `MaterialApp`, `Scaffold`, `AppBar`, `Center`, dan `Text`.
3. **Pemisahan File (Modularitas):** Memisahkan tampilan halaman ke file tersendiri (`hello_world.dart`) dari `main.dart`.
4. **Layout Kolom (`Column`):** Mengatur tata letak widget secara vertikal menggunakan `Column` (`column_widget.dart`).
5. **Layout Baris (`Row`):** Mengatur tata letak widget secara horizontal menggunakan `Row` (`row_widget.dart`).
6. **Form Input Data:** Membuat form input barang dengan `TextField` dan `TextEditingController` (`ui/produk_form.dart`).
7. **Navigasi Antar Halaman & Passing Data:** Berpindah halaman menggunakan `Navigator.push` dan mengirimkan data produk ke halaman detail (`ui/produk_detail.dart`).
8. **ListView & Card:** Menampilkan daftar data produk menggunakan `ListView`, `Card`, dan `ListTile` (`ui/produk_page.dart`).
